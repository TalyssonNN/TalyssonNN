## 📊 BI de Acompanhamento OFS

Projeto de **Business Intelligence** desenvolvido para transformar dados operacionais em indicadores de acompanhamento e desempenho.

O dashboard possibilita acompanhar informações das equipes e transformar registros operacionais em uma visão gerencial para suporte à tomada de decisão.

### 📈 Indicadores

* 👷 Equipes ativas
* ⏳ Turnos pendentes de finalização
* 🚚 Disponibilidade de caminhões
* 📊 Status das equipes
* 🚛 Status dos caminhões
* 🏆 Ranking de equipes por percentual de execução
* 👨‍💼 Indicadores de desempenho por supervisor
* 📅 Análises por período

### 🔎 Recursos

* Filtros por dia, mês e ano
* Filtros por supervisor
* Filtros por equipe
* Indicadores operacionais
* Rankings de desempenho
* Visualização consolidada das operações
* Apoio à tomada de decisão
